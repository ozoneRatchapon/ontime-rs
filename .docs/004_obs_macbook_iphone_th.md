# งานสดด้วย MacBook + iPhone + OBS + ontime-rs

คู่มือนี้สำหรับงาน online หรืองานที่ถ่ายทอดสด โดยมีอุปกรณ์แค่ MacBook หนึ่งเครื่องกับ iPhone หนึ่งเครื่อง (plan 022)

```
iPhone ──(Continuity Camera)──▶ MacBook: OBS ──▶ YouTube / Facebook Live
                                        ▲
                     ห้อง ontime-rs: หน้า obs-countdown, obs-timer (Browser Source)
```

## สิ่งที่ต้องมี

- **MacBook:** macOS 13 (Ventura) ขึ้นไป
- **iPhone:** iPhone XR ขึ้นไป, iOS 16 ขึ้นไป, ล็อกอิน Apple ID เดียวกับ Mac และเปิด Wi‑Fi กับ Bluetooth ทั้งสองเครื่อง
- **มือถือ Android:** ใช้แอปอย่าง DroidCam หรือ Camo แทน Continuity Camera
- **OBS Studio:** ฟรี จาก https://obsproject.com
- **ขาตั้งมือถือ:** ตั้งแนวนอน
- **เน็ต:** upload อย่างน้อยประมาณ 5–10 Mbps ใช้สาย LAN ได้จะดีที่สุด

## 1. เตรียมห้องใน ontime-rs

1. เปิดห้องที่ https://master.ontime-team.pages.dev แล้วใส่กำหนดการลงใน rundown
2. ตั้งชื่องานที่ **Settings → Project** (ชื่อนี้จะขึ้นบนหน้านับถอยหลัง)
3. ไปที่ **Settings → Custom views** แล้วกด **Add OBS views** จะได้ 2 หน้า:
   - `obs-countdown`: หน้านับถอยหลังก่อนเริ่มงาน
   - `obs-timer`: timer ของ event ที่กำลังเล่น พื้นหลังโปร่งใส ใช้วางทับภาพกล้อง
4. ในตารางจะมีที่อยู่ของแต่ละหน้า ถ้าห้องล็อกไว้ ที่อยู่จะมี `?token=` ต่อท้ายมาด้วย ให้ copy ทั้งบรรทัด

## 2. ต่อ iPhone เข้า OBS

1. วาง iPhone บนขาตั้งใกล้ Mac แนวนอน ล็อกจอไว้
2. ใน OBS ที่ช่อง **Sources** กด **+** แล้วเลือก **Video Capture Device**
3. เลือก iPhone ในช่อง Device (ถ้าไม่เห็น ให้เช็กเรื่อง Apple ID, Wi‑Fi และ Bluetooth)

## 3. ใส่หน้าของ ontime-rs ใน OBS

กด **+** แล้วเลือก **Browser** ตั้ง Width `1920` Height `1080` แล้ววางที่อยู่ของหน้าลงในช่อง URL

**Scene "รอเริ่ม"**: ใช้หน้า `obs-countdown` ตัวอย่าง:

```
…/external/obs-countdown/?token=…&to=19:30&label=เริ่มในอีก&bg=0b1020&accent=7c5cff&font=Prompt
```

| ตัวเลือก | ความหมาย |
|---|---|
| `to=19:30` | นับถอยหลังถึงเวลานี้ (เวลาเดียวกับที่ห้องแสดง) ถ้าไม่ใส่ จะนับถึงเวลาเริ่ม event แรก |
| `label=…` | ข้อความเหนือตัวเลข |
| `done=…` | ข้อความที่แสดงเมื่อนับถึงศูนย์ (ค่าเริ่มต้น: Starting now) |
| `title=…` | ชื่อหัวเรื่อง (ค่าเริ่มต้น: ชื่องานใน Project) |
| `logo=https://…` | รูปโลโก้ |
| `bg=0b1020` | สีพื้นหลัง หรือ `transparent` (ค่าเริ่มต้น) |
| `color=…` `accent=…` | สีตัวหนังสือ / สีตัวเลข |
| `font=Prompt` | ฟอนต์จาก Google Fonts (ภาษาไทยแนะนำ Prompt, Kanit, Sarabun) |
| `next=0` | ซ่อนชื่อ event แรก |

**Scene "ถ่ายทอด"**: ให้ภาพกล้องอยู่ล่างสุด แล้ววางหน้า `obs-timer` ไว้บนสุด

```
…/external/obs-timer/?token=…&pos=br&size=12&font=Prompt
```

| ตัวเลือก | ความหมาย |
|---|---|
| `pos=` | ตำแหน่ง: `tl` `tr` `bl` `br` (ค่าเริ่มต้น) หรือ `c` (กลางจอ) |
| `size=12` | ความสูงของตัวเลข เป็น % ของจอ |
| `title=0` | ซ่อนชื่อ event |
| `idle=show` | แสดงกล่องไว้แม้ไม่มีอะไรเล่นอยู่ (ค่าเริ่มต้นคือซ่อน) |
| `bg=none` | ไม่มีกล่องพื้นหลัง |
| `color=` `warning=` `danger=` | สีปกติ / สีตอนใกล้หมดเวลา / สีตอนเลยเวลา |
| `font=` | ฟอนต์จาก Google Fonts |

หน้า `obs-timer` จะซ่อนตัวเองเมื่อหยุด จางลงเมื่อ pause และเมื่อเลยเวลาจะนับต่อแบบมีเครื่องหมายลบด้วยสีแดง สีจะเปลี่ยนตามเวลา warning และ danger ที่ตั้งไว้ใน event

## 4. ตั้งค่าการ stream

1. ใน OBS ไปที่ **Settings → Stream** เลือก YouTube หรือ Facebook แล้วใส่ stream key ของงาน
2. ไปที่ **Settings → Output / Video**:
   - ถ้าเน็ตดี ใช้ 1080p30
   - ถ้า upload ต่ำ ลดเหลือ 720p30
3. ก่อนขึ้นจริง ทดลอง stream แบบ "ไม่สาธารณะ" (unlisted / private) ก่อน 1 รอบ

## 5. ระหว่างงาน

- **คนคุมเวลา:** เปิด `editor` ในเบราว์เซอร์บน Mac เครื่องเดียวกับที่รัน OBS แล้วกด start / next / เพิ่มเวลา หน้าใน OBS จะเปลี่ยนตามเอง
- **มีทีมงานอีกคน:** เปิด `cuesheet` บนมือถือหรือเครื่องของตัวเองได้
- **ผู้พูดที่อยู่ไกล:** ส่งลิงก์หน้า `timer` ให้เปิดบนเครื่องของตัวเอง จะเห็นเวลาตรงกับในห้อง
- **สลับ scene:** ใช้ hotkey ของ OBS (Settings → Hotkeys)

## เช็กลิสต์ก่อนขึ้น live

- [ ] iPhone ชาร์จเต็มหรือเสียบสายชาร์จไว้ ปิดการแจ้งเตือน (โหมด Focus)
- [ ] Mac เสียบปลั๊ก ปิดแอปที่ไม่ใช้
- [ ] กำหนดการใน rundown ถูกต้อง เวลา `to=` ตรงกับเวลาเริ่มงาน
- [ ] Scene "รอเริ่ม" นับถอยหลังถูก Scene "ถ่ายทอด" เห็น timer ตอนกด start
- [ ] ทดลอง stream แบบ unlisted แล้ว ทั้งเสียงและภาพปกติ
- [ ] จด token ของห้องไว้ เผื่อต้องเปิดหน้าใหม่

## ถ้ามีปัญหา

| อาการ | ทางแก้ |
|---|---|
| หน้าใน OBS ว่างหรือขึ้น Unauthorized | ที่อยู่ไม่มี `?token=` หรือ token ผิด ให้ copy ใหม่จาก Custom views |
| ตัวเลขนับถอยหลังขึ้น `--:--` | ยังไม่ได้ใส่ `to=` และใน rundown ยังไม่มี event |
| ตัวเลขจาง | เน็ตหลุด หน้าจะต่อใหม่เอง |
| ไม่เห็น iPhone ใน OBS | ล็อกอิน Apple ID เดียวกัน, เปิด Wi‑Fi และ Bluetooth, ปลดล็อกจอแล้วล็อกใหม่ |
| ฟอนต์ไม่เปลี่ยน | ชื่อฟอนต์ต้องตรงกับใน Google Fonts เช่น `Noto+Sans+Thai` |
